# Sign Language Recognition System

## Setup
pip install -r requirements.txt

## Run (order me)
1. python collect_data.py   # har gesture ke ~400 images (s = save on/off, n = next class)
2. python train_model.py    # model train + accuracy, confusion matrix, graphs
3. python recognize.py      # real-time recognition + speech (q = quit)
